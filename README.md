# NailDesk — دستیار شخصی ناخن‌سالن 🌸

یک PWA کامل و **کاملاً آفلاین** برای یک ناخن‌کار حرفه‌ای که همه‌چیز را روی **یک گوشی آیفون** مدیریت می‌کند: مشتری‌ها، نوبت‌ها با تقویم شمسی، طراحی ناخن با ویرایشگر ده‌ناخنی، فهرست خدمات، ماشین‌حساب قیمت، آمار و پشتیبان‌گیری دستی.

> بدون حساب کاربری، بدون سرور، بدون ارسال داده به بیرون. همه داده‌ها فقط در حافظه محلی دستگاه (IndexedDB) ذخیره می‌شود.

سه سند فارسی کامل در ریشه پروژه:
`NAILDESK_PROJECT_PRESENTATION_FA.txt` (معرفی کامل محصول) · `NAILDESK_DEPLOYMENT_GUIDE_FA.txt` (راهنمای گام‌به‌گام ویندوز ۱۱ و GitHub Pages) · `NAILDESK_QA_AUDIT_REPORT_FA.txt` (گزارش صادقانه ممیزی کیفیت)

---

## ویژگی‌ها

- **راه‌اندازی شخصی** — نام هنرمند (با پیشنهاد «ساحل» به‌عنوان نمونه در کادر خالی) و نام سالن؛ خوش‌آمدگویی «سلام {نام} جان 🌸»
- **میزکار (داشبورد)** — نوبت‌های امروز، برچسب «بعدی» برای قرار پیشِ‌رو، آمار ماه جلالی، دسترسی سریع
- **ویرایشگر طراحی ناخن** — ده ناخن مستقل (۵ چپ + ۵ راست) با فرم (چهارگوش/گرد/بادامی/بالرینا/بیضی)، طول، رنگ (پالت ۲۸ رنگی + رنگ سفارشی)، جلا (براق/مات/شیمر/کروم)، الگو (ساده/فرنچ/امبره/خط‌دار/خال‌خالی/مرمری با رنگ و تراکم)، تزئینات (گلیتر/سنگ/قلب/ستاره تا ۸ عدد در هر ناخن) و یادداشت هر ناخن؛ **کپی/چسباندن بین ناخن‌ها**، «این رنگ برای همه»، «استایل کامل برای همه»، واگرد/ازنو تا ۵۰ حرکت؛ **ذخیره خودکار پیش‌نویس** با نشانگر «در حال ذخیره / ذخیره شد / خطا»
- **گالری طرح‌ها** — ذخیره، تکثیر، علاقه‌مندی، فیلتر وضعیت (ایده/پیشنهاد/تأیید شده)، جست‌وجو، **خروجی PNG و SVG از خود گالری**
- **مدیریت مشتری‌ها** — شماره تماس اختیاری، سلیقه‌ها (فرم/رنگ/طول)، سابقه کامل خدمات، طرح‌های مشتری با «استفاده دوباره»، بایگانی/بازیابی، حذف بدون تخریب سوابق
- **تقویم شمسی (جلالی)** — ماه‌های فروردین تا اسفند با سال کبیسه، نوبت‌سازی با **تشخیص تداخل زمانی** (نوبت‌های لغوشده مانع نیستند؛ تداخل در هر تاریخی که انتخاب کنید بررسی می‌شود)، وضعیت برنامه‌ریزی/انجام‌شده/لغوشده
- **فهرست خدمات** — دسته، قیمت و مدت پیش‌فرض، فعال/غیرفعال
- **ماشین‌حساب قیمت** — ردیف‌های خدمتی و **ردیف دلخواه دستی**، تعداد، تخفیف درصدی یا مبلغی با اعتبارسنجی سخت‌گیرانه، ثبت پیش‌فاکتور با **عکس لحظه‌ای قیمت** (تغییر نرخ‌های بعدی روی قبلی‌ها اثر ندارد)
- **آمار** — نوبت‌ها، درآمد ثبت‌شدهٔ ماه (مجموع خدمات انجام‌شده — نه رسید نقدی)، مشتری فعال، طرح ذخیره‌شده
- **پشتیبان‌گیری JSON** — خروجی کامل + بازیابی با اعتبارسنجی چندلایه، پشتیبان اضطراری قبل از جایگزینی و تراکنش اتمی (هر خطا = بی‌تغییر ماندن داده‌ها)
- **نصب به‌صورت PWA** — افزودن از Safari به صفحه اصلی؛ پس از نخستین بازدید همه منابع (حتی فونت) کش می‌شوند و آپدیت‌ها فقط با تأیید شما اعمال می‌شوند

## فناوری

React 18 + TypeScript (سخت‌گیرانه) + Vite + Dexie.js (IndexedDB) + jalaali-js + vite-plugin-pwa + SVG خالص. بدون هیچ سرویس ابری، کلید API یا درخواست شبکه‌ای در زمان اجرا (پس از نصب اولیه).

## اجرا (ویندوز ۱۱ / هر پلتفرم)

پیش‌نیاز: Node.js نسخهٔ ۲۰ یا بالاتر (LTS). راهنمای کامل مبتدی در `NAILDESK_DEPLOYMENT_GUIDE_FA.txt`.

```bash
npm ci          # نصب دقیق بر اساس package-lock.json
npm run dev     # محیط توسعه روی http://localhost:5173
npm test        # ۸۹ تست خودکار (Vitest + fake-indexeddb)
npm run build   # بررسی نوع + ساخت نسخه تولید در dist/
npm run preview # پیش‌نمایش نسخه تولید روی http://localhost:4173
```

⚠ فایل `index.html` را دابل‌کلیک نکنید؛ ماژول‌های ES و Service Worker به وب‌سرور واقعی نیاز دارند (`dev` یا `preview`).

## استقرار روی GitHub Pages

1. کل پوشه پروژه (شامل `.github/workflows/deploy.yml`) را به مخزن عمومی `naildesk` در شاخه `main` بفرستید (GitHub Desktop ساده‌ترین راه است).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**
3. گردش‌کار خودکار: `npm ci` → `npm test` → `npm run build` → انتشار پوشه `dist`.
4. آدرس نهایی به شکل `https://USERNAME.github.io/naildesk/` است.

مسیر پایه روی `./` نسبی است، آدرس‌های مانیفست و فونت نسبی‌اند و ناوبری مبتنی بر تب است؛ پس برنامه زیر هر زیرمسیری درست کار می‌کند و رفرش هرگز ۴۰۴ نمی‌دهد. جزئیات کامل و عیب‌یابی در راهنمای استقرار.

## نصب روی آیفون (Safari)

1. با Safari آدرس برنامه را باز کنید (نخستین بازدید اینترنت می‌خواهد).
2. منتظر پیام «برنامه برای استفاده آفلاین آماده است.» بمانید.
3. **Share → Add to Home Screen → Add** (این اقدام دستی است؛ iOS نصب خودکار ندارد).
4. از این پس مثل یک اپ مستقل تمام‌صفحه اجرا می‌شود و **بدون اینترنت هم کامل کار می‌کند**.

## پشتیبان‌گیری و بازیابی

- مسیر: **تنظیمات → داده‌ها و پشتیبان‌گیری**
- فایل خروجی: `naildesk-backup-YYYY-MM-DD.json` (تاریخ محلی) شامل تنظیمات، مشتری‌ها، خدمات، نوبت‌ها، طرح‌ها، پیش‌فاکتورها و پیش‌نویس طراحی با حفظ همه شناسه‌ها و روابط
- بازیابی: اعتبارسنجی کامل (شناسه برنامه، نسخه ساختار، انواع داده، ارجاع‌ها، مقادیر مالی، ساختار ده‌ناخنی) → خلاصهٔ محتوا → پیشنهاد پشتیبان اضطراری → تأیید صریح → جایگزینی در **یک تراکنش اتمی**
- توصیه: هفته‌ای یک‌بار یا پس از ورود داده‌های جدید؛ چند نسخهٔ اخیر را در Files نگه دارید.

## حریم خصوصی و داده‌ها

- تنها «منبع حقیقت» IndexedDB مرورگر است؛ هیچ داده‌ای به هیچ سروری نمی‌رود
- بدون تحلیلگر، تبلیغ، فونت/آیکون CDN یا هر منبع خارجی — فونت وزیرمتن به‌صورت محلی همراه برنامه است
- تاریخ‌ها به‌صورت کلید محلی `YYYY-MM-DD` و ساعت `HH:mm` ذخیره می‌شوند (هرگز timestamp یو‌تی‌سی برای کلید)؛ نمایش تاریخ‌های رکورد هم از تبدیل محلی استفاده می‌کند — تست‌شده در UTC و Asia/Tehran
- مبالغ فقط **عدد صحیح تومان**؛ ارقام فارسی/عربی ورودی نرمال می‌شوند
- نوبت‌ها و پیش‌فاکتورها «عکس لحظه‌ای» نام/قیمت/مدت خدمات را نگه می‌دارند
- درخواست «ذخیره‌سازی پایدار» (`navigator.storage.persist`) برای کاهش پاک‌شدن خودکار داده‌ها
- دادهٔ مرورگر در برابر «Clear Website Data» و حالت ناشناس مصون نیست — پشتیبان منظم ضروری است

## محدودیت‌های واقعی

همگام‌سازی چنددستگاهی، اعلان از راه دور، بانک ابری، شبیه‌سازی سه‌بعدی، تولید طرح با AI و پشتیبان‌گیری خودکار ابری **وجود ندارند** (عمداً). تقویم به‌جای نمای هفتگی جداگانه، ترکیب «نمای ماه + جزئیات روز» دارد. فهرست کامل در بخش ۱۷ سند ارائه.
